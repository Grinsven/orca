material-folder-icons/*.svg and material-folder-icon-map.json come from the Material Icon Theme
(https://github.com/material-extensions/vscode-material-icon-theme, v5.39.0, commit
92a9c5b25a5f4ae4c6a475fb99e434caffef5871), trimmed to 43 folder icons plus the default
folder. The open variants and the default folder are built the way the theme's own build does
(src/scripts/svg/generateOpenFolderIcons.ts and src/core/generator/folderGenerator.ts). MIT
